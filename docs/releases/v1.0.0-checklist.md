## Publication blockers

The default manual workflow dispatch is a deterministic, credential-free dry run and cannot create a release. Real candidate trust is supplied only through protected key, fingerprint, and policy-hash controls; source configuration intentionally grants no signer by itself. Do not set the protected `RELEASE_EXTERNAL_BLOCKERS_APPROVAL` value or dispatch publication until: the tag signer and signing identities and notarization credentials are supplied and independently verified; all four clean-machine architecture rows pass; OpenAI and release-candidate Ollama smoke pass; packet capture and performance budgets pass; destructive removal checks pass; name/trademark, logo use, and license review are approved externally. The separate protected publication workflow must then re-download and reverify the exact attested draft and confirm the public `/releases/latest` response. GitHub drafts are intentionally invisible to that public endpoint.
