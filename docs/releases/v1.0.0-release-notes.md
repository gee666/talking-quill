# Talking Quill v1.0.0

First release candidate for local-first system-wide dictation on Windows and macOS, with Raw/Smart processing, 37 provider adapters, optional On-Screen Awareness, voice commands, custom vocabulary, Past Echoes, and scoped local-data controls.

Checksums cover every uploaded asset except the checksum file itself.

Repository configuration does not claim a signing identity, clean-machine result, live-provider result, hardware measurement, or manual acceptance. Those require the evidence named in the checklist. Draft verification uses the authenticated GitHub API; the user-facing public-latest update path is verified separately only after publication.
