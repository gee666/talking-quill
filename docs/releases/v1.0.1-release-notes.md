# Talking Quill v1.0.1

Talking Quill v1.0.1 is a reliability release for Pi Smart processing and live microphone feedback.

## Changes

- Runs the authenticated, canonical npm-global Pi 0.81.1 installation in place inside the contained Electron utility process.
- Uses a hard 120-second provider/IPC response deadline. Pi receives an earlier abort reserve for bounded process-tree cleanup, which is observed separately and cannot delay the timeout response.
- Uses the user's effective Pi profile and environment by default, including configured custom models and provider extensions. Settings includes a disclosed opt-out. Pi tools, sessions, project context, skills, prompts, and themes remain disabled in both modes.
- Lists models once through Pi's runtime and sends transcript completions directly to the exact configured model without a preliminary catalog request.
- Improves Pi progress, cancellation, diagnostics, and stale-model behavior.
- Maps real PCM RMS to a smoothed perceptual microphone level with accessible numeric and state text, and resets it on teardown.
- Displays the application version and short source revision.

## Distribution

No GitHub release is created by this local verification work. The expected unsigned local Windows x64 candidate name is `Talking-Quill-1.0.1-win-x64.exe`. Official publication remains subject to signing, provenance, installer, and release-control gates.
