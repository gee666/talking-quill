# Talking Quill v1.0.2

Talking Quill now runs a compatible user-installed Pi command directly in place.

- Removed Pi package copying, closure manifests, version allowlists, private profiles, OAuth merging, native containment add-ons, and release-specific Pi materialization.
- Added Windows PATH/PATHEXT plus npm/pnpm-home discovery and flexible absolute manual executable selection.
- Added bounded CLI capability checks, tolerant model parsing, strict model/thinking validation, stdin-only prompts, hard timeouts, cancellation, and process-tree termination.
- Pi uses its normal user environment, configuration, authentication, models, extensions, and `PI_CODING_AGENT_DIR` state.
- Preserved welcome-flow, timeout, Raw fallback, and widget reliability work from v1.0.1.

The expected unsigned Windows x64 installer is `Talking-Quill-1.0.2-win-x64.exe`. Local verification does not publish a release.
